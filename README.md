# Restaurant Operations Simulator

## Project Overview
The Restaurant Operations Simulator is a Python-based simulation project that models customer flow and service operations in a restaurant. It helps analyse waiting times, resource utilisation, service bottlenecks and staffing requirements.

## Objectives
- Simulate customer arrivals and service processes.
- Analyse waiting times at different service stages.
- Identify operational bottlenecks.
- Compare staffing configurations.
- Support better resource allocation decisions.

## Technologies Used
- Python
- SimPy
- Gradio
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Simulation Methodology
The project uses:
- Exponential distribution for customer inter-arrival times.
- Triangular distribution for service times.
- Queueing theory to analyse waiting lines.
- Discrete-event simulation using SimPy.

## Dashboard Features
- Manager Overview
- Customer Experience Analysis
- Demand Analysis
- Queue Dynamics
- Staffing Decisions
- Reports and Data Downloads

## How to Run
1. Download the `.ipynb` notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Run all cells in order.
5. The Gradio dashboard will launch with a shareable browser link.

## Note
The simulation uses assumed arrival and service-time distributions for academic analysis. Results represent simulated scenarios and are not actual restaurant operational data.
